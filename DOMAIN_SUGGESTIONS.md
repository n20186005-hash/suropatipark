# Kandidat Domain `.id`

Kandidat berikut menggunakan nama tempat dan pola Bahasa Indonesia yang ringkas. Status pendaftaran domain berubah secara waktu nyata. Pada pemeriksaan antarmuka PANDI, hasil status eksplisit tidak ditampilkan secara terbaca; karena itu daftar ini **bukan** pernyataan bahwa domain masih tersedia.

| Kandidat | Pertimbangan |
| --- | --- |
| `panduantamansuropati.id` | Menjelaskan bahwa situs adalah panduan, bukan operator taman. |
| `jelajahtamansuropati.id` | Bernuansa wisata lokal dan cocok untuk pengalaman kunjungan. |
| `ruangsuropati.id` | Ringkas, berfokus pada taman sebagai ruang publik. |
| `kanopimenteng.id` | Mengikuti konsep desain situs dan kaitannya dengan Menteng. |
| `infotamansuropati.id` | Jelas untuk penggunaan sebagai sumber informasi pengunjung. |

Sebelum pembelian, periksa ulang kandidat di [PANDI](https://pandi.id/search-domain) atau melalui registrar .id yang terakreditasi. Setelah domain dipilih, masukkan URL produksi hanya pada konstanta `site` di `astro.config.mjs`, lalu jalankan `pnpm build` ulang untuk mengaktifkan canonical, Open Graph URL absolut, dan sitemap otomatis.
